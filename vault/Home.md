# Mom's Design Build — Marketing Memory

This is Summer's (and Claude's) shared memory for momsdesignbuild.com — not a
mirror of the site's content, a record of *why things are the way they are*
and *what happened when*. Start every conversation here.

## Read first, every conversation
1. [[website/change-log]] — what changed recently, and why
2. [[decisions]] — standing calls that shape future work (skim titles/dates)
3. Anything in [[inbox]] — quick captures waiting to be filed

## Sections
- [[brand/voice-guide|brand/]] — voice, audience, offers, competitors
- [[campaigns]] — one note per campaign: goal, dates, results, learnings

- [[decisions]] — one note per real decision, with the why
- [[inbox]] — quick captures; file into the right folder when seen

## Write last, every conversation
Made a site change? Add a dated line to [[website/change-log]].
Made a real decision (not just a small edit)? Add a note to [[decisions]].
Learned something worth remembering? Update the right note — don't duplicate.
